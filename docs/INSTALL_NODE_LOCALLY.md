# Установка Node.js и зависимостей локально

## Проблема
IDE показывает ошибки, что React не найден, потому что `node_modules` не установлены локально.

## Решение

### Вариант 1: Установить Node.js (если нужно для разработки)

#### macOS (через Homebrew):
```bash
brew install node
```

#### Или скачать с официального сайта:
https://nodejs.org/

### Вариант 2: Установить зависимости локально (если Node.js уже есть)

```bash
cd frontend
npm install
```

Это создаст папку `node_modules/` с всеми зависимостями, и IDE перестанет показывать ошибки.

### Важно

**Для работы приложения на VM это НЕ нужно!** 

Зависимости устанавливаются автоматически внутри Docker контейнера при сборке:
```bash
docker-compose build frontend
```

Ошибки линтера в IDE - это нормально, если `node_modules` нет локально. Код все равно будет работать в Docker.

### Если не хотите устанавливать Node.js локально

Можно просто игнорировать ошибки линтера - они не влияют на работу приложения в Docker.
